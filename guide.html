上手手册

从零到装上第一个社区插件大约十分钟。命令按 2026-08 公测版核对。

1

准备 Node.js 22+

官方包是 @deepseek-ai/dsh。用 nvm / fnm / 官网安装均可，先确认 node -v ≥ 22。

2

启动 Web UI

在项目目录执行 npx -y @deepseek-ai/dsh web，打开终端打印的地址（常见 http://127.0.0.1:3080）。

3

填入模型密钥

设置 → 模型，写入 DeepSeek API Key。密钥落在本机凭据文件，页面只回显脱敏信息。

4

选择工作区

点「选择工作区」，把当前项目目录加进去。未选择时，会话输入框不可用。

5

安装插件

在目录里复制命令，默认写入 web profile。装完后重新执行 dsh web。

6

无界面任务

脚本和 CI 用 dsh --profile headless "任务描述"。推理档位常见为 low / high / max。

常用命令

点击即可复制。

速查
npx -y @deepseek-ai/dsh web
dsh --profile headless "总结这个仓库"
dsh plugin --profile web add git+https://github.com/owner/repo.git
dsh plugin --profile web remove owner/repo
dsh --profile web --dump-config

官方文档 官方仓库

社区插件尚未统一进 npm。当前最稳的安装方式是 dsh plugin --profile web add git+https://github.com/作者/仓库.git。 个别 monorepo 需要 link: 本地目录，以作者 README 为准。

常见问题

安装 DeepSeek Harness 与社区插件时最常被问到的几件事。

DeepSeek Harness 是什么？

DeepSeek Harness（简称 DSH）是 DeepSeek 开源的 Agent 运行时。官方口号是 Everything is a Plugin：模型、工具、技能、会话、沙箱和界面都以插件形式存在，可以在不改核心源码的情况下重组。

它和 Codex CLI、Claude Code 有什么区别？

定位同类，都是终端/工作区里的编程智能体。DSH 的差异是开源、插件化、Web UI 与社区皮肤生态更重；Codex CLI / Claude Code 更偏向厂商一体、开箱即用。

如何安装社区插件？

在本站插件目录复制命令，一般是 dsh plugin --profile web add git+https://github.com/作者/仓库.git，然后重新执行 dsh web。

插件列表的数据从哪来？

来自 GitHub topic dsh-plugin。站点内置快照保证秒开，也可用 Actions 定时同步。完整静态列表见 全部插件，生态分析见 洞察。

如何收藏感兴趣的插件？

在插件卡片右上角点 ★ 即可收藏，收藏记录保存在浏览器本地（localStorage）。在插件目录的「我的收藏」分类里可查看全部收藏。换浏览器不会同步。
