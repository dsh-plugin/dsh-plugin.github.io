DeepSeek Harness 插件工坊

DeepSeek Harness（DSH）与 Codex CLI、Claude Code 同类，但是开源 Agent 运行时：模型、工具、皮肤、会话都能用插件替换。本站从 GitHub topic dsh-plugin 汇总社区仓库，方便中文开发者检索、复制 dsh plugin 安装命令，并把站点发布到 GitHub Pages。

快速开始 Node.js 22+
# 启动 Web UI
$ npx -y @deepseek-ai/dsh web
→ http://127.0.0.1:3080

# 安装社区插件
$ dsh plugin --profile web add \
    git+https://github.com/owner/repo.git
$ dsh web

为什么做成工坊

给中文用户一条能装上、能发布的路径，而不是又一份仓库列表。

1

和 Codex CLI 同类，但可重组

官方口号是 Everything is a Plugin。Cordis 负责挂载与依赖，界面、工具、循环都能换，不必改核心源码。

2

目录直接连 GitHub

主数据来自 github.com/topics/dsh-plugin。内置快照秒开，前台再轻量同步热门仓库。

3

为 GitHub Pages 而生

纯静态，无后端、无构建。Fork 后在 Settings → Pages 选 main / root，即可挂上自己的工坊。
